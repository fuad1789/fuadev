# CRITICAL DESIGN RULE

DO NOT use one universal website structure for every business.

The website structure, layout, imagery, typography, colors, sections, and user journey MUST depend on the actual business category.

For example:

- A restaurant should not look like a law firm.
- A dental clinic should not look like a nightclub.
- A construction company should not look like a beauty salon.
- A luxury hotel should not look like an auto repair shop.
- A local cafe should not use the same structure as a corporate consulting company.
- A fitness center should have a different visual rhythm than a medical practice.
- An architecture studio should feel different from a furniture store.

First understand the industry, then choose the correct creative direction.
